❓ Pertanyaan Umum

Apakah aplikasinya bisa jalan offline?

Ya. Semua aplikasi PecutAigan berupa satu file HTML yang jalan langsung di browser — tanpa internet, tanpa install. Cocok untuk aplikasi kasir toko, kasir laundry, nota bengkel, dan lainnya.

Sekali bayar atau langganan?

Sekali bayar Rp129.000 per aplikasi, pakai selamanya. Tidak ada biaya bulanan atau langganan.

Bagaimana cara belinya?

Klik tombol Tokopedia atau Shopee di tiap produk. Setelah pembayaran, file aplikasi + panduan dikirim ke kamu.

Apakah data usaha saya aman?

Data tersimpan di perangkatmu sendiri (localStorage browser), tidak dikirim ke server mana pun. Privasi terjaga.

Bisa dipakai di HP?

Bisa. Buka file aplikasinya di browser HP Android/iPhone atau laptop — tampilannya menyesuaikan layar.
